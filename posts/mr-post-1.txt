[SIZE=5][B]kepubify[/B] v5[/SIZE]
[SIZE=4]Convert EPUBs to Kobo EPUBs.[/SIZE]

[B]Features:[/B]
[LIST]
[*]Standalone and cross platform.
[*]Works from the command line (also by dragging and dropping on Windows).
[*]Also has a [URL="https://pgaskin.net/kepubify/try/"]web interface[/URL].
[*]Fast (40-80x faster than converting with Calibre).
[*]Optionally custom CSS, smarten punctuation, find/replace, and more.
[*]Automatically fix common problems which cause layout issues for KEPUBs.
[*]Optionally pre-convert books for use in Calibre.
[*]Batch conversion with control over the output file structure (see [URL="https://ci.appveyor.com/project/pgaskin/kepubify/builds/30198538#L171"]here[/URL] for detailed examples).
[*]Nearly identical output to KEPUBs from the Kobo Store.
[*]Very tolerant of malformed OPF and XHTML documents.
[/LIST]

[B]New in v5:[/B]
[LIST]
[*]Faster conversion, lower memory usage.
[*]Output may differ slightly from v4 (including koboSpan numbering), especially for malformed books.
[*]New kepub renderer bug workaround for non-canonical encoded paths in manifest/ncx/nav causing double-counted page numbers and erratic navigation.
[*]Many bugfixes: self-closing formatting elements, spans in special elements, whitespace handling, heading hyphenation, content document paths with special characters.
[*]More workarounds for malformed books: XML 1.1 declarations, malformed OPFs, non-UTF-8 charsets, invalid zip attributes.
[*]CLI improvements: skip/copy/reprocess existing KEPUBs, preserve file attributes.
[*]Dummy titlepage now uses the real cover image if known (or detected, if enabled).
[*]See the [URL="https://pgaskin.net/kepubify"]website[/URL] or [URL="https://github.com/pgaskin/kepubify/releases/tag/v5.0.0"]downloads[/URL] for the full changelog.
[/LIST]
